# Meral — Handmade Haven

Storefront for Meral, a handmade brand: embroidered bags, wedding
handkerchiefs, and a cosmetics line coming later.

TanStack Start + React 19 + Tailwind 4. Arabic/English, RTL by default.

```sh
bun install
bun run dev      # http://localhost:5173
bun run build
```

## Backend

The admin dashboard and the JSON API live in a separate repository,
[merals-handmade-haven-backend](https://github.com/AhmedYasser2019/merals-handmade-haven-backend)
(Laravel + Filament).
